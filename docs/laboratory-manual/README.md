# AS7343 Laboratory Manual

This directory will contain the practical laboratory manual for constructing, operating, testing, and improving the AS7343 Laboratory instrument.

The manual will preserve the central idea of the project:

> Scientifically useful measurements can be made with inexpensive components when the instrument is built carefully, tested honestly, and used thoughtfully.

Planned sections include:

1. Purpose and design philosophy
2. Parts, tools, and approximate cost
3. Instrument construction
4. Firmware and desktop-software installation
5. Basic operation
6. Blank, sample, transmittance, and absorbance measurements
7. Calibration and quantitative analysis
8. Kinetic measurements
9. Instrument validation
10. Example experiments
11. Limitations, troubleshooting, and improvements
