## Bartel Technologies

## Overview

The AS7343 Laboratory project demonstrates that scientifically useful analytical instruments can be constructed from inexpensive, commercially available components without sacrificing scientific rigor or quantitative validation. The long-term goal of this project is to develop, validate, and openly document affordable scientific instrumentation that others can reproduce, evaluate, and improve.


The current laboratory platform is built around the following major components:

- Raspberry Pi Pico
- Adafruit AS7343 multispectral sensor
- Custom CircuitPython firmware and Python software
- LED-based illumination system
  
The laboratory platform has been evaluated against a Thermo Electron Spectronic 20D+ spectrophotometer as part of its ongoing performance validation.

## Current Capabilities

- Quantitative absorbance spectroscopy
- Visible and near-infrared spectral measurements
- Spectral comparison
- Kinetic measurements
- CSV data export
- Calibration curve generation
- Quantitative nitrate analysis
- Instrument validation
  

## Philosophy

This project is guided by a simple principle:

> Careful measurement, transparent methods, and thoughtful analysis are more important than expensive equipment.

## Status

Active development. New analytical methods, documentation, and software improvements are added as they are completed and validated.

Contributions, questions, and thoughtful discussion are always welcome.

## Documentation

The development of the laboratory platform, analytical methods, and validation studies is documented through the LSRC Technical Report Series. Additional software, hardware, and experimental documentation is maintained within this repository.
