AS7343 Laboratory

Bartel Technologies

Measure Carefully. Think Deeply.

Overview

The AS7343 Laboratory project demonstrates that scientifically useful analytical instruments can be constructed from inexpensive, commercially available components without sacrificing careful measurement or quantitative validation.

The current instrument is based on

Raspberry Pi Pico
Adafruit AS7343 multispectral sensor
custom Python/CircuitPython software
low-cost LED illumination

and has been evaluated against a Thermo Spectronic 20D+ spectrophotometer.

Current capabilities
Visible absorbance spectroscopy
Near infrared spectroscopy
Spectral comparison
Kinetic measurements
CSV data export
Calibration curves
Quantitative nitrate analysis
Instrument validation
Documentation

The project is documented through the LSRC Technical Report Series.

Philosophy

This project is based on a simple idea:

Careful measurement, transparent methods, and thoughtful analysis are more important than expensive equipment.

Status

Active development.
